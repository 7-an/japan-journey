# Japan — Beyond the screen

A three-chapter classroom presentation website: animated opening, anime stories and Hokkaido winter scenery.

Open index.html or visit the GitHub Pages site. Click Begin the journey to start the opening and music. Scroll or use arrow keys to explore.
