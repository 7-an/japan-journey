## Playback

The HTML presentation plays the silent H.264 opening alongside an independent AAC background-music track. Music continues through the final held image, all slide changes and intro replay. The track is ten minutes long and loops; turn it off manually when the talk is finished. Start presentation is a user gesture that starts both media files. Use the music button and volume slider for live adjustments.

The PPTX embeds both media files, configures autoplay, and sets the audio to loop across all ten slides. Its soundtrack lowers the volume from 21 to 22.8 seconds. The opening ends at 23 seconds and holds its last frame; advance manually to slide 2. Native PowerPoint playback is not tested on this host. The standalone v11 MP4 contains pictures only; the HTML player supplies music from bgm.m4a. Spoken script: 1,110 words; rehearse the full presentation under 9:30.

The offline package must be fully extracted. Keep Japan.html, opening.mp4, bgm.m4a and the assets directory together. No network connection is required.
